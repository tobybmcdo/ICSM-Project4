# ICSM Project 4

## StudyFlow

Flashcards, the easy way. StudyFlow is a lightweight study-guide prototype for students. Choose a class, select course materials, and create a guide with review cards.

### Run it

Open `index.html` in a browser. The prototype is self-contained and does not need a build step.

### Prototype scope

The current version uses sample Canvas classes and sample course content. It supports a guided class and source selection flow, Quizlet-compatible tab-separated flashcard export, and printing or saving the guide as a PDF. Live Canvas login, importing course links, and reading real slides or videos require Canvas developer credentials and a backend integration.
